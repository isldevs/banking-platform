# iSLDevs

Java & Spring Boot backend development, focused on enterprise systems, distributed architecture, and banking applications.

## Featured Project

### [iSLDevs Banking Platform](https://github.com/isldevs/banking-platform)

An evolving enterprise banking platform built with **Java, Spring Boot, microservices, double-entry accounting, event-driven architecture, and secure APIs**.

**Implemented:** OAuth2/OIDC, customer/KYC lifecycle, accounts, funding, internal transfers, ledger entries, Kafka, notifications, and audit.

**Roadmap:** General ledger, financial posting, AML/fraud, payment orchestration, settlement, reconciliation, FX, SWIFT/ISO 20022, and lending.
